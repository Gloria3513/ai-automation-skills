# 파일 이름 통일

## 기본 규칙
`날짜_내용_번호.확장자` — 예: `2026-10-15_행사사진_01.jpg`

- 날짜: 사진은 찍은 날짜, 문서는 파일 날짜. 사용자가 날짜를 정해 주면 그 날짜.
- 내용: 사용자에게 한 낱말로 묻는다(예: 행사사진, 회의록, 영수증). 마음대로 짓지 않는다.
- 번호: 01부터 두 자리.

## 순서
1. 파일 목록을 읽는다.
2. 규칙을 확인받는다. 사용자가 다른 규칙을 말하면 그 규칙을 따른다.
3. **'지금 이름 → 새 이름' 표를 전부 보여 주고 "이대로 바꿀까요?"라고 묻는다.**
4. 허락하면 바꾼다. 새 이름이 겹치면 번호를 하나 올린다.
5. 끝나면 바꾼 개수를 알려 주고, 되돌릴 수 있게 '새 이름 → 원래 이름' 표를 `이름바꾸기_기록.csv`로 남긴다.

## 하지 말 것
- 확장자(.jpg, .hwp 등)는 바꾸지 않는다.
- 파일 내용은 열어서 고치지 않는다. 이름만 바꾼다.

# 여러 문서 → 한 장 요약

## 순서
1. 읽을 문서 목록과 개수를 먼저 보여 준다.
2. 누구에게 보여 줄 요약인지 묻는다(예: 팀장, 기관 담당자, 나). 그에 맞춰 길이와 말투를 정한다.
3. 아래 틀로 쓴다.
   - **한 줄 요약**
   - **결정된 것** (문서 이름)
   - **해야 할 일** — 누가 · 무엇을 · 언제까지 (문서 이름)
   - **아직 정하지 못한 것**
4. 문서마다 말이 다르면 하나로 정하지 말고 "문서 A는 ~, 문서 B는 ~"라고 둘 다 적는다.
5. 저장할 형식을 묻는다(docx · md · txt). 기본은 `요약_날짜.docx`.

## 하지 말 것
- 문서에 없는 숫자·이름·날짜를 만들지 않는다.
- 원본 문서를 고치지 않는다.

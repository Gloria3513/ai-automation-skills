# 폴더 정리

## 하는 일
사용자가 정해 준 폴더 **안에서만** 파일을 종류·날짜별 하위 폴더로 옮긴다.

## 순서
1. 폴더 안 파일 목록을 읽고, 몇 개인지·어떤 종류인지 먼저 알려 준다.
2. 나눌 방법을 하나 제안한다. 기본은 아래 표.
   | 종류 | 하위 폴더 |
   |---|---|
   | 사진(jpg, png, heic) | `사진/년-월` (찍은 날짜, 없으면 파일 날짜) |
   | 문서(hwp, docx, pdf, txt) | `문서` |
   | 표(xlsx, csv) | `표` |
   | 그 밖 | `기타` |
3. **어떤 파일이 어디로 가는지 표로 보여 주고 "이대로 옮길까요?"라고 묻는다.** 허락 전에는 아무것도 옮기지 않는다.
4. 허락하면 옮긴다. 같은 이름이 이미 있으면 덮어쓰지 말고 이름 뒤에 `_2`를 붙인다.
5. 끝나면 옮긴 개수와 폴더별 개수를 표로 알려 준다.

## 하지 말 것
- 파일을 지우지 않는다.
- 정해 준 폴더 밖은 열지도, 옮기지도 않는다.
- 숨김 파일과 설정 파일(`.`으로 시작하는 파일)은 건드리지 않는다.

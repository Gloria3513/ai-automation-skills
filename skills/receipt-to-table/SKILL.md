# 사진·문서 → 표

## 순서
1. 어떤 칸(열)을 뽑을지 먼저 묻는다. 영수증이면 기본으로 제안: `날짜 | 가게 | 금액 | 무엇을 샀나 | 파일 이름`.
2. 파일을 하나씩 읽어 한 줄씩 채운다.
3. **글자가 흐리거나 잘려서 확실하지 않은 칸은 추측하지 말고 `[확인 필요]`라고 적는다.**
4. 다 채우면 표를 보여 주고, `[확인 필요]`가 몇 칸인지 알려 준다.
5. 저장할 이름을 확인받고 `정리표_날짜.csv`(엑셀에서 열림)로 저장한다. 원본 파일은 그대로 둔다.
6. 금액 칸이 있으면 맨 아래에 합계를 적는다.

## 개인정보
- 주민등록번호·계좌번호·카드번호가 보이면 표에 옮기지 말고 `(가림)`으로 적는다.
- 명단은 사용자가 고른 칸만 옮긴다.

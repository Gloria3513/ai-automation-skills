# 사진 → 블로그 초안

## 순서
1. 사진 목록을 찍은 시각 순서로 늘어놓는다. 사진 정보에 날짜·위치가 있으면 함께 적는다.
2. 사진을 보고 장면을 나눈다(예: 도착 · 행사 · 점심 · 돌아오는 길).
3. **사진에 보이는 것과 사용자가 말해 준 것만 쓴다.** 맛·느낌·사람 이름처럼 확인 안 된 것은 사용자에게 묻는다.
4. 사람 얼굴이 크게 나온 사진, 차량 번호·영수증·주소가 보이는 사진은 따로 표시하고 넣을지 묻는다.
5. 초안 형식:
   - 제목 후보 3개
   - 본문: 장면마다 짧은 글 + `[사진: 파일 이름]` 자리
   - 마지막 문장은 요약 대신 그날의 한 장면으로 닫는다
6. 초안을 `블로그초안_날짜.md`로 저장한다. **블로그에 올리는 일은 사람이 직접 한다.**

## 말투
- 사용자가 예전에 쓴 글이 있으면 그 말투를 따른다. 없으면 담백한 '~해요'체.
- "도움이 되셨길 바랍니다" 같은 정형 문장은 쓰지 않는다.

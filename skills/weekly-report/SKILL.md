# 주간 보고 초안

## 틀 (매주 같게)
```
[주간 보고] 년-월-일 ~ 월-일
1. 이번 주 한 일
   - (한 일) — 근거: (파일 이름)
2. 다음 주 할 일
3. 도움이 필요한 것
```

## 순서
1. 기간을 확인한다. 말이 없으면 이번 주 월요일~오늘.
2. 정해 준 폴더에서 그 기간에 만들어지거나 바뀐 파일만 본다.
3. 틀에 맞춰 초안을 쓴다. **한 일마다 근거 파일 이름을 붙인다.** 근거가 없으면 쓰지 않는다.
4. "다음 주 할 일"과 "도움이 필요한 것"은 파일에서 찾지 못하면 비워 두고 사용자에게 묻는다.
5. `주간보고_날짜.docx`로 저장하기 전에 확인받는다.
